# House Rules — 사람처럼 쓰기 (실측 기반)

사람 카드뉴스 120세트와 AI 비중이 높은 블로그 120세트를 비교해서 둘을 실제로 가르는 규칙만 남겼다.
요체 리듬은 마케팅 기사 1.6만 문장에서 쟀다.

이 파일이 `quick-rules.md`보다 우선한다. 단, 의미 불변·Do-NOT·서법 보존은 이 파일보다도 위다.

---

## 1. 리듬

- 문장 길이를 들쭉날쭉하게 쓴다. 짧은 한마디와 긴 문장을 섞는다.
- 연결어미(~고, ~며, ~지만)로 길게 잇지 말고 끊는다.
- 연결어미 바로 뒤에 쉼표를 찍지 않는다.
- 쉼표는 문장 열 개 중 세 개 이하.
- 명사구를 늘어놓지 말고 동사로 쓴다. 셋씩 묶어 나열하지 않는다.
- 긍정 일색으로 쓰지 않는다. 아쉬움과 실패도 그대로 쓴다.
  - 윤문할 때: 원문에 있는 아쉬움·실패를 미화하거나 지우지 않는다. 없던 단점을 지어내지도 않는다.
  - 새로 쓸 때: 아쉬운 점을 하나 이상 담는다. 근거는 사용자가 준 재료 안에서만 찾는다.

> '연결어미로 길게 잇지 말고 끊는다'와 quick-rules E-1('인접 문장을 이어 장문 1개')이 부딪히면, 연결어미 사슬을 끊는 쪽을 먼저 한다. 장문은 연결어미 대신 관형절이나 인용으로 만든다.

## 2. AI 글에 유난히 많은 단어

| 단어 | AI 글 배수 | 기준 |
|---|---|---|
| 핵심 | 10.8배 | 쓰지 않음 |
| 다만 | 7.1배 | 쓰지 않음 |
| 및 | 6.6배 | 쓰지 않음 |
| 단순히 | 2.7배 | 쓰지 않음 |
| 결국 | 4.8배 | 한 번까지 |
| 확인 | 4.8배 | 한 번까지 |
| 중요 | 1.6배 | 한 번까지 |

대체 예시 (문맥에 맞는 것을 고른다)
- 핵심 → 가장 큰, 알맹이, 제일 먼저 볼 것, 또는 문장을 바꿔 주어로 바로 말하기
- 다만 → 그런데, 하지만, 대신, 문장을 끊고 새로 시작
- 및 → 와/과, 그리고, 쉼표 없이 두 문장으로
- 단순히 → 그냥, ~만, 또는 삭제
- 결국 → 그래서, 끝내, 또는 삭제
- 확인 → 보다, 알아보다, 따져 보다, 찾아보다
- 중요 → 놓치면 안 되는, 먼저 챙길, 크게 갈리는

고유명사·인용·제품명 안에 든 단어는 세지 않고 고치지도 않는다.

## 3. AI 단골 표현 금지

- 정리·결산: 결론적으로, 요약하면, 정리하자면, 요컨대
- 의의 과장: 시사하는 바, 주목할 만, 매우 중요
- 꾸밈말: 흥미롭게도, 놀랍게도, 진정한, 심오한
- 개념어: 패러다임, 메커니즘, 여정, 중추적
- 상투구: ~ 역할을 한다, 살펴보겠습니다, 마무리하며, ~라고 할 수 있다
- 지어낸 기본값 이름: 민수, 지수, 철수, 영희 (새로 쓸 때 예시 인물이 필요하면 흔하지 않은 이름을 쓰거나 이름 없이 "한 직장인"처럼 쓴다. 원문에 실존 인물로 나온 이름은 Do-NOT이라 그대로 둔다.)

## 4. 사람 글에 많은 표현

사람 글에서 2.5~10배 많이 나온다. **요체 글이면 하나 이상 넣는다.**

~거죠 / ~거예요 / ~겁니다, ~는데요, ~죠, ~잖아요, 요즘, 사실, 그런데, 이런

- 윤문할 때는 내용을 더하지 않고 기존 문장의 종결어미·접속어를 바꾸는 식으로만 넣는다.
- 해라체(~다) 글에 요체 표현을 끼워 넣지 않는다. register를 바꾸는 것이라 금지다.

## 5. 억지로 피하지 않아도 되는 것

'~를 통해', '~것이다'는 사람도 많이 쓴다. 이것만 보고 고치지 않는다.

## 6. 고칠지 판단하는 기준

위 2·3장 패턴과 1장 리듬 위반이 **한 글에 두 종류 이상** 보이면 고친다.
하나만 보고 고치면 사람 글도 34%를 잘못 잡았다. 한 종류만 보이면 "손볼 게 거의 없다"고 알리고, 사용자가 원할 때만 그 부분만 고친다.

## 7. 종결어미

- 한 어미 유형이 전체 문장의 40%를 넘지 않는다.
- 같은 유형을 세 문장 연속 쓰지 않는다. 두 문장 연속도 되도록 피한다.
- 한 글에 최소 세 가지 유형을 쓴다.
- 현재형 '~한다·~는다'는 글 전체에서 세 번 이하.
- 기본 배분: 사실은 과거형, 해석은 현재형, 정리는 명사형이나 짧은 질문.
  - 시제를 바꿔서 사실관계가 달라지면 바꾸지 않는다(지금도 유효한 사실을 과거형으로 돌리지 않는다).

### 요체 글의 실측 리듬 (마케팅 기사 1.6만 문장)

| 유형 | 비율 |
|---|---|
| ~합니다·~습니다 | 37% |
| ~어요 | 20% |
| ~는데요 | 8% |
| 감탄·반말 질문 | 8% |
| ~고요 | 6% |
| ~죠 | 5% |
| ~예요 | 5% |

사람 에디터는 요체와 합니다체를 한 글 안에서 섞는다. '~어요/~예요'만 이어지면(AI 글은 83%) 바로 티가 난다.
요체·합니다체 섞기는 둘 다 존댓말이라 register 위반이 아니다. 해라체 글을 존댓말로 바꾸는 건 위반이다.
(사용자가 구어체 정도를 고르면 `register-levels.md`가 이 문단과 철칙 4를 대체한다.)

이 장의 수치는 구어체 정도 50(블로그·카드뉴스) 기준이다. 다른 레벨의 종결 조건은 `register-levels.md`를 따른다.

## 8. 공개 연구로 더한 규칙

근거와 수치는 `research-notes.md`에 있다.

- 문두 접속부사 뒤에 쉼표를 찍지 않는다. "그리고, / 하지만, / 그런데, / 따라서," (KatFish, ACL 2025)
- 부사격 조사 뒤 쉼표("~에서, / ~으로,")도 되도록 뺀다.
- "특히 / 무엇보다 / 예를 들어 / 또한"은 각각 두 번까지. AI 글은 예시·강조 연결어에 쏠린다(교양교육연구 2025).
- 같은 내용어를 짧은 글에서 네 번 넘게 반복하지 않는다. 지시어나 생략으로 받는다. 고유명사·주제어는 예외.
- 사물에 높임 '-시-'를 붙이지 않는다. "품절이십니다" → "품절입니다"
- 새로 쓸 때 출처·통계·후기를 지어내지 않는다.
