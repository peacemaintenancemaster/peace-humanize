# House Rules — 사람처럼 쓰기 (실측 기반)

사람 카드뉴스 120세트와 AI 비중이 높은 블로그 120세트를 비교해서 둘을 실제로 구분하는 규칙만 남겼다.
요체 리듬은 마케팅 기사 1.6만 문장에서 쟀다.

이 파일이 `quick-rules.md`보다 우선한다. 단, 의미 불변·Do-NOT·서법 보존은 이 파일보다도 위다.

---

## 1. 리듬

- 문장 길이를 들쭉날쭉하게 쓴다. 짧은 한마디와 긴 문장을 섞는다.
- 연결어미(~고, ~며, ~지만)로 길게 잇지 말고 끊는다.
- 단, 끊은 결과 끝소리가 같은 짧은 문장이 이어지면 안 된다. 40자 미만 문장이 같은 끝 두 음절(예: "~니다", "~어요")로 세 번 연달아 끝나지 않게 한다. 이때는 두 문장을 하나로 합치거나 끝소리가 다른 어미로 바꾼다. 같은 "~니다"인 ~했습니다·~합니다·~입니다는 귀로는 같은 소리다.
- 연결어미 바로 뒤에 쉼표를 찍지 않는다.
- 쉼표는 문장 열 개 중 세 개 이하.
- 명사구를 늘어놓지 말고 동사로 쓴다. 셋씩 묶어 나열하지 않는다.
- 긍정 일색으로 쓰지 않는다. 아쉬움과 실패도 그대로 쓴다.
  - 윤문할 때: 원문에 있는 아쉬움·실패를 미화하거나 지우지 않는다. 없던 단점을 지어내지도 않는다.
  - 새로 쓸 때: 아쉬운 점을 하나 이상 담는다. 근거는 사용자가 준 재료 안에서만 찾는다.

> 끊기와 합치기의 기준: 연결어미가 두 개 넘게 이어진 사슬은 끊는다. 짧은 문장이 같은 끝소리로 셋 이어지면 합친다. 합칠 때는 쉼표 없이 관형절이나 연결어미 하나로 잇는다. quick-rules E-1('인접 문장을 이어 장문 1개')도 같은 방식으로 적용한다.

## 2. AI 글에 유난히 많은 단어

| 단어 | AI 글 배수 | 기준 |
|---|---|---|
| 핵심 | 10.8배 | 쓰지 않음 |
| 다만 | 7.1배 | 쓰지 않음 |
| 및 | 6.6배 | 쓰지 않음 |
| 단순히 | 2.7배 | 쓰지 않음 |
| 결국 | 4.8배 | 한 번까지 |
| 확인 | 4.8배 | 한 번까지 |
| 중요 | 1.6배 | 한 번까지 |

대체 예시 (문맥에 맞는 것을 고른다)
- 핵심 → 주요, 요점, 가장 큰, 또는 문장을 바꿔 주어로 바로 말하기
- 다만 → 그런데, 하지만, 대신, 문장을 끊고 새로 시작
- 및 → 와/과, 그리고, 쉼표 없이 두 문장으로
- 단순히 → 그냥, ~만, 또는 삭제
- 결국 → 그래서, 끝내, 또는 삭제
- 확인 → 점검, 검토, 검사, 조회 (뜻이 맞으면 "보다"도 가능)
- 중요 → 필요한, 우선, 필수, 결정적인

고유명사·인용·제품명 안에 든 단어는 세지 않고 고치지도 않는다.
대체어를 고를 때도 9장(어색한 고유어 금지)을 따른다. 한자어를 피하려고 "알맹이", "따져 보다" 같은 말을 끌어오지 않는다.

## 3. AI 단골 표현 금지

- 정리·결산: 결론적으로, 요약하면, 정리하자면, 요컨대
- 의의 과장: 시사하는 바, 주목할 만, 매우 중요
- 꾸밈말: 흥미롭게도, 놀랍게도, 진정한, 심오한
- 개념어: 패러다임, 메커니즘, 여정, 중추적
- 상투구: ~ 역할을 한다, 살펴보겠습니다, 마무리하며, ~라고 할 수 있다
- 지어낸 기본값 이름: 민수, 지수, 철수, 영희 (새로 쓸 때 예시 인물이 필요하면 흔하지 않은 이름을 쓰거나 이름 없이 "한 직장인"처럼 쓴다. 원문에 실존 인물로 나온 이름은 Do-NOT이라 그대로 둔다.)

## 4. 사람 글에 많은 표현

사람 글에서 2.5~10배 많이 나온다. **요체 글이면 하나 이상 넣는다.**

~거죠 / ~거예요 / ~겁니다, ~는데요, ~죠, ~잖아요, 요즘, 사실, 그런데, 이런

- 윤문할 때는 내용을 더하지 않고 기존 문장의 종결어미·접속어를 바꾸는 식으로만 넣는다.
- 해라체(~다) 글에 요체 표현을 끼워 넣지 않는다. register를 바꾸는 것이라 금지다.

## 5. 억지로 피하지 않아도 되는 것

'~를 통해', '~것이다'는 사람도 많이 쓴다. 이것만 보고 고치지 않는다.

## 6. 고칠지 판단하는 기준

위 2·3장 패턴과 1장 리듬 위반이 **한 글에 두 종류 이상** 보이면 고친다.
하나만 보고 고치면 사람 글도 34%를 잘못 잡았다. 한 종류만 보이면 "수정할 부분이 거의 없다"고 알리고, 사용자가 원할 때만 그 부분만 고친다.

## 7. 종결어미

- 한 어미 유형이 전체 문장의 40%를 넘지 않는다.
- 같은 유형을 세 문장 연속 쓰지 않는다. 두 문장 연속도 되도록 피한다.
- 한 글에 최소 세 가지 유형을 쓴다.
- 현재형 '~한다·~는다'는 글 전체에서 세 번 이하.
- 기본 배분: 사실은 과거형, 해석은 현재형, 정리는 명사형이나 짧은 질문.
  - 시제를 바꿔서 사실관계가 달라지면 바꾸지 않는다(지금도 유효한 사실을 과거형으로 돌리지 않는다).

### 요체 글의 실측 리듬 (마케팅 기사 1.6만 문장)

| 유형 | 비율 |
|---|---|
| ~합니다·~습니다 | 37% |
| ~어요 | 20% |
| ~는데요 | 8% |
| 감탄·반말 질문 | 8% |
| ~고요 | 6% |
| ~죠 | 5% |
| ~예요 | 5% |

사람 에디터는 요체와 합니다체를 한 글 안에서 섞는다. '~어요/~예요'만 이어지면(AI 글은 83%) 바로 티가 난다.
요체·합니다체 섞기는 둘 다 존댓말이라 register 위반이 아니다. 해라체 글을 존댓말로 바꾸는 건 위반이다.
합쇼체는 유형을 나눠도 끝소리가 모두 "~니다"라서 1장의 끝소리 규칙에 가장 자주 걸린다. 합쇼체가 많은 글일수록 문장을 길게 잡는다.
(사용자가 구어체 정도를 고르면 `register-levels.md`가 이 문단과 철칙 4를 대체한다.)

이 장의 수치는 구어체 정도 50(블로그·카드뉴스) 기준이다. 다른 레벨의 종결 조건은 `register-levels.md`를 따른다.

## 8. 공개 연구로 더한 규칙

근거와 수치는 `research-notes.md`에 있다.

- 문두 접속부사 뒤에 쉼표를 찍지 않는다. "그리고, / 하지만, / 그런데, / 따라서," (KatFish, ACL 2025)
- 부사격 조사 뒤 쉼표("~에서, / ~으로,")도 되도록 뺀다.
- "특히 / 무엇보다 / 예를 들어 / 또한"은 각각 두 번까지. AI 글은 예시·강조 연결어에 쏠린다(교양교육연구 2025).
- 같은 내용어를 짧은 글에서 네 번 넘게 반복하지 않는다. 지시어나 생략으로 받는다. 고유명사·주제어는 예외.
- 사물에 높임 '-시-'를 붙이지 않는다. "품절이십니다" → "품절입니다"
- 새로 쓸 때 출처·통계·후기를 지어내지 않는다.

## 9. 어색한 고유어 금지

AI 윤문은 한자어를 피하려다 순우리말 동사나 비유를 억지로 끌어온다. "중간 값도 돼요", "알아서 깔려요", "PASS가 찍힙니다", "스크립트를 돌려 보세요" 같은 문장이다. 사람은 이런 자리에 한자어를 쓴다. 구어체 정도 100에서도 마찬가지다.

**원칙**
- 구어체는 어미와 담화표지로 만든다. 어휘를 고유어로 바꿔서 만들지 않는다.
- 그 분야에서 표준으로 쓰는 한자어(설치·실행·입력·선택·표시·검사·수정·삭제·가능·지원)는 그대로 둔다.
- 원문에 있던 한자어를 고유어로 바꾸지 않는다. 원문의 고유어가 어색하면 한자어로 바꿔도 된다.

**자주 보이는 패턴**

| 어색한 표현 | 자연스러운 표현 |
|---|---|
| 중간 값도 돼요 | 중간 값도 가능해요 |
| 알아서 깔려요 / 스킬을 깔면 | 자동으로 설치돼요 / 스킬을 설치하면 |
| PASS가 찍힙니다 | PASS가 표시됩니다 |
| 스크립트를 돌려 보세요 | 스크립트를 실행해 보세요 |
| 숫자가 빠졌는지도 봐 줘요 | 숫자 누락도 검사해요 |
| 처음부터 써 줘요 | 새로 작성해요 |
| 둘을 가르는 기준 | 둘을 구분하는 기준 |
| 문장을 손봐요 | 문장을 수정해요 |
| 관용구를 걷어내요 / 덜어내요 | 관용구를 빼요 / 삭제해요 |
| 짚어 볼게요 | 살펴볼게요 / 정리할게요 |
| 결이 다르다 | 성격이 다르다 |
| 알맹이 | 요점 / 주요 내용 |
| 담아냈어요 / 풀어냈어요 / 녹여냈어요 | 담았어요 / 설명했어요 / 반영했어요 |

**예외**
- 허락의 "해도 돼요"는 자연스럽다. 명사 뒤에 붙어 가능을 뜻하는 "~도 돼요"만 고친다.
- 고유어가 그 맥락의 표준이면 둔다("파일을 열다", "글을 쓰다", "버튼을 누르다").
- 에세이처럼 문학적인 글이 원문이면 원문의 고유어 비유는 보존한다.

**quick-rules와의 관계:** F-4(명사화 환원)와 F-7(범용 정책동사 해체)이 없애려는 것은 영어를 옮긴 명사화와 "확대·강화·구축" 같은 빈 동사다. 뜻이 분명한 한자어 동사(설치하다·실행하다·검사하다)는 해체 대상이 아니다.

## 10. 지어내지 않기 (담백하게)

AI는 글을 그럴듯하게 만들려고 아무도 말하지 않은 사연을 붙인다. "저희 팀은 매번 이 작업을 손으로 해 왔습니다. 그러다 ~라는 결론에 이르렀습니다" 같은 문장이다. 누가 만들었는지, 언제 무엇을 겪었는지, 왜 시작했는지를 사용자가 말한 적이 없는데 써 넣는다. 사실이 아니면 그 글 전체를 믿을 수 없게 된다.

- 사용자가 주지 않은 배경·경험·동기·일화·시기·주체를 만들지 않는다. "우리 팀이 만들었다", "처음엔 ~했다가 바꿨다", "고객 반응이 좋았다" 같은 문장이 해당한다.
- 사용자가 "팀이 쓴다"고 했으면 "팀이 쓴다"까지만 쓴다. "팀이 만들었다"로 바꾸지 않는다. 주어와 시점을 넓히지 않는다.
- 글에 이야기나 근거가 필요해 보이면 지어내지 말고 사용자에게 묻는다. 물을 수 없으면 그 부분을 비워 두고 무엇이 빠졌는지 알린다.
- 담백하게 쓴다. 무엇인지, 무엇을 하는지, 어떻게 쓰는지를 사실대로 적는다. 감동이나 서사로 포장하지 않는다.
- 예시 문장이 필요하면 예시라고 밝힌다.
- 윤문할 때는 철칙 5(원문에 없던 주장·사례 금지)와 같은 규칙이다.
