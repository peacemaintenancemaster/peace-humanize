# 공개 자료에서 가져온 보강 규칙

자체 규칙을 뒷받침하거나 새로 더한 근거다. 한국어 자료만 썼다. 각 규칙에 근거의 세기를 적었다.

- **강**: 동료 심사 논문, 정량 수치 있음
- **중**: 학술지 논문이지만 표본이 작음, 또는 공공기관 조사
- **약**: 실무자 기록·블로그. 참고만 하고 FAIL 기준으로 쓰지 않음(WARN)

---

## 1. 쉼표 — 강

**출처:** Park et al., "KatFishNet: Detecting LLM-Generated Korean Text through Linguistic Feature Analysis", ACL 2025. 사람 글 470편 vs LLM 글 1,624편(에세이·시·논문 초록). https://aclanthology.org/2025.acl-long.1030/

| 지표 (에세이) | 사람 | LLM |
|---|---|---|
| 쉼표가 있는 문장 비율 | 26.31% | 61.03% |
| 연결어미 뒤 쉼표 비율 | 4.10% | 19.83% |
| 형태소당 쉼표 | 1.13% | 2.56% |
| 쉼표 상대 위치(0=문두) | 0.09 | 0.18 |

쉼표 특징만으로 에세이 탐지 AUROC 94.88이 나왔다. 한국어 AI 티 중 가장 강한 신호다.

**반영**
- 자체 규칙 "쉼표는 문장 열 개 중 세 개 이하"가 사람 에세이 26%와 맞아떨어진다. 그대로 둔다.
- **새 규칙: 문두 접속부사 뒤 쉼표 금지.** "그리고, / 하지만, / 그런데, / 따라서, / 또한," 같은 쉼표는 한국어 맞춤법상 필요 없고 LLM이 영어 구두점 습관으로 넣는다(논문 본문 분석).
- **새 규칙(WARN): 부사격 조사 뒤 쉼표.** "~에서, / ~으로, / ~에게," 뒤 쉼표는 전문가 평가에서 LLM 특징으로 지적됐다.

## 2. 명사보다 용언 — 강

**출처:** 같은 KatFish 논문. 사람은 용언(동사·형용사)과 어미를 많이 쓰고, LLM은 체언(명사)을 많이 쓴다. 품사 n-gram 다양성도 사람이 높다.

**반영:** 자체 규칙 "명사구를 늘어놓지 말고 동사로 쓴다"의 근거. 스크립트가 '-화/-성/-적' 명사화 밀도를 WARN으로 보고한다.

## 3. 같은 어휘 반복 — 강

**출처:** 같은 논문의 Zipf·Heaps 분석. LLM은 특정 어휘를 반복하고 새 단어가 늘어나는 속도가 느리다.

**반영(WARN):** 같은 내용어가 짧은 글 안에서 4번 넘게 나오면 알린다. 고유명사·주제어는 반복이 자연스러우니 기계적으로 바꾸지 않는다. 지시어("이 방식", "그 제품")나 생략으로 받을 수 있는 반복만 손본다.

## 4. 예시·강조 연결어 쏠림 — 중

**출처:** 박종향·김은영, 「생성형 AI 텍스트와 인간 텍스트의 내용 및 문체 비교 연구」, 『교양교육연구』 19(6), 2025. 대학 과제 69편(2021 AI 미사용 vs 2025 AI 활용). https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART003291987

접속 표현 전체 빈도는 비슷했지만, AI 활용 글은 조건 연결보다 **예시·강조 연결어**에 기댔다. 교수자 평가에서는 사고·문체의 획일성과 존재하지 않는 참고문헌이 지적됐다.

**반영**
- WARN: "특히 / 무엇보다 / 예를 들어 / 또한"이 각각 두 번 넘게 나오면 알린다.
- 집필 모드: 출처·인용·통계를 지어내지 않는다. 사용자가 준 재료에 없으면 쓰지 않는다.

## 5. 사물 존칭 — 중

**출처:** 문화체육관광부 공공언어 인식 조사(3,000명). '과도한 높임 표현'이 개선 필요 응답률 1위(93.3%). 예: "품절이십니다" → "품절입니다". 높임 '-시-'는 사람이 주어일 때만 쓴다.

**반영:** 레벨과 상관없이 FAIL. 구어체 정도를 높여 친절하게 쓰려다 생기기 쉽다.

## 6. 실무자 관찰 — 약

**출처:** 디지털마케터 「말투와 문체 지시하기」, 「클로드와 챗GPT 말투가 티 나는 이유」(2026). 블로그 교정 기록과 커뮤니티 관찰. https://www.digitalmarketer.co.kr/class/prompt-design-in-practice/tone-and-style-instructions

- "~로서 기능합니다", "~역할을 합니다" 같은 serves-as 직역 → "~입니다"
- 습관성 은유: "두 갈래로 나뉩니다", "두 축으로", "봐야 할 자리" 같은 표현
- 지시형 도입: "상상해 보세요", "생각해 보세요"로 여는 문단
- 과잉 공감·칭찬("정말 좋은 질문이에요!")
- 톤은 형용사가 아니라 확인 가능한 조건으로 지시해야 결과가 안정된다 → `register-levels.md`가 이 방식을 따른다

**반영:** "기능합니다", "상상해 보세요"는 WARN. 은유는 quick-rules D-14가 이미 다룬다.

## 일부러 반영하지 않은 것

- **띄어쓰기 오류 흉내.** KatFish에서 사람 글은 의존명사·보조용언 띄어쓰기를 더 자주 어긴다. 하지만 실제로 내보낼 글에 맞춤법 오류를 일부러 넣을 수는 없다.
- **문장 길이 고정 수치.** 한국어 이독성 연구에서 신문 기사 평균 어절 수 같은 기준은 찾지 못했다. 자체 규칙의 "들쭉날쭉하게"와 스크립트의 변동계수 경고로 대신한다.
- **영어권 AI 문체 연구.** 한국어에 그대로 옮길 수 있는지 검증되지 않았다.
