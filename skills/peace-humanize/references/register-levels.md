# 구어체 정도 (0~100)

세 구간 모두 존댓말이다. 0은 가장 단정한 합쇼체이고 100은 가장 말에 가까운 요체다. 해라체(~다)와 반말은 이 척도에 없다.

레벨은 "친근하게" 같은 형용사가 아니라 확인할 수 있는 조건으로 정의한다. 막연한 톤 지시는 결과가 들쭉날쭉하기 때문이다. `house_check.py --level N`이 이 조건을 잰다.

## 레벨을 고르면 달라지는 것

레벨을 고르면 SKILL.md 철칙 4(register 보존)가 그 레벨로 대체된다. 원문이 해라체여도 레벨을 고르면 존댓말로 바꾼다. 해라체를 그대로 두려면 "원문 톤 유지"를 고른다.

**의미 불변·내용 앵커·서법 보존·숫자 보존은 레벨과 상관없이 그대로다.** 문체를 바꾸면서 내용을 더하거나 빼지 않는다.

레벨을 바꾸면 변경률이 30%를 쉽게 넘는다. 그래서 레벨 전환 작업에서는 변경률 30% 경고를 보고만 하고, 50% 롤백 규칙은 적용하지 않는다. 대신 숫자 누락·앵커 누락 검사를 더 엄격하게 본다.

## 세 기준점

### 0 — 단정한 존댓말 (공지·보도자료·리포트·격식 뉴스레터)

| 항목 | 조건 |
|---|---|
| 종결 | 합쇼체(~습니다·~입니다) 중심. 요체는 10% 이하 |
| 종결 변주 | 합쇼체 안에서 바꾼다. 사실은 과거(~했습니다), 해석은 현재(~합니다), 정리는 ~입니다. 같은 형태 50% 이하 |
| 허용 | 짧은 질문 한두 개, 보고서 항목의 명사형 개조식(-음/-함) |
| 금지 | 이모지, 감탄사, 축약형(근데·이건·게), 담화표지로 말 걸기 |
| 문장 | 주어를 밝힌다. 명사구 나열 대신 동사 |
| 호흡 | 합쇼체는 끝소리가 모두 "~니다"라서 짧은 문장이 이어지면 같은 소리가 빠르게 반복된다. 40자 미만 합쇼체 문장을 세 개 연달아 두지 않는다. 합쇼체 문장 평균은 40자 이상 |
| 호흡 만드는 법 | 짧은 문장 두 개를 관형절이나 연결어미 하나로 합친다(쉼표 없이). 목록·캡션은 명사형으로 끝낸다. 질문을 한두 개 섞는다 |
| 표기 | 명사형은 '있음/없음'(있슴·없슴 아님) |

### 50 — 블로그·카드뉴스·마케팅 기사 (하우스 룰 기본값)

하우스 룰 7장의 실측 리듬을 목표로 한다. 합쇼체와 요체를 한 글 안에서 섞는다.

| 유형 | 목표 |
|---|---|
| ~합니다·~습니다 | 35% 안팎 |
| ~어요 | 20% 안팎 |
| ~는데요 | 8% |
| 질문·감탄(요체) | 8% |
| ~고요 / ~죠 / ~예요 | 각 5~6% |

- 사람 글 표현(~거죠, ~는데요, ~잖아요, 요즘, 사실, 그런데, 이런)을 하나 이상
- 같은 유형 40% 이하, 3연속 금지, 3가지 이상
- 축약형은 드물게(근데·이건은 한 글에 한두 번까지)

### 100 — 친근한 대화체 (인스타 캡션·캐주얼 뉴스레터·커뮤니티 글)

| 항목 | 조건 |
|---|---|
| 종결 | 요체 70% 이상. 합쇼체 20% 이하 |
| 자주 쓰는 어미 | ~거든요, ~잖아요, ~더라고요, ~는데요, ~죠, ~네요 |
| 허용 | 축약형(근데, 이건, 그건, 게, 거), 주어 생략, 질문·감탄, "진짜·완전·되게" 같은 강조 부사 |
| 사람 글 표현 | 두 개 이상 |
| 어휘 | 구어체는 어미로 만든다. 설치·실행·입력·가능 같은 한자어를 고유어로 바꾸지 않는다(하우스 룰 9장) |
| 문장 | 15자 이하 짧은 문장이 자주 나온다. 한 문단 두세 문장 |
| 종결 배분 | 같은 유형 40% 이하, 4가지 이상 |

## 기준점 사이의 숫자 (예: 25, 75)

가까운 두 기준점의 조건을 비율대로 섞는다. 25라면 0을 바탕으로 하되 문장 네 개 중 하나쯤을 요체로 바꾼다. 75라면 100을 바탕으로 하되 합쇼체를 30% 안팎 남긴다.

## 모든 레벨 공통

- 존댓말이 아닌 문장(해라체·반말)은 10% 이하. 제목, 명사형 항목은 세지 않는다.
- 사물 존칭 금지: "품절이십니다", "커피 나오셨습니다" → "품절입니다", "커피 나왔습니다". 높임 '-시-'는 사람이 주어일 때만 쓴다(문화체육관광부 공공언어 인식 조사, 3,000명 중 93.3%가 개선 필요로 응답).
- 과잉 공감·칭찬("정말 좋은 질문이에요!", "너무 멋져요")을 새로 넣지 않는다.
- 하우스 룰 2·3장 금지어·금지 표현은 그대로 지킨다.

## 원문 레벨 추정

`house_check.py`가 존댓말 문장의 종결로 원문 구어체 정도를 추정한다. 합쇼체는 0, ~어요·~예요·~고요는 80, ~는데요·~죠·기타 요체는 100으로 놓고 평균을 낸 다음 구어 표지로 보정한다.

존댓말 문장이 절반이 안 되는 글(해라체 칼럼, 반말 글)은 추정값 대신 "존댓말 아님"으로 표시한다. 이때 질문의 추천값은 "원문 톤 유지"다.
