# 구어도 레벨 (0~100)

0은 가장 공적인 글이고 100은 친구에게 말하듯 쓴 반말 구어다. 사용자가 고른 레벨에 맞춰 종결어미, 어휘, 문장 모양을 정한다.

레벨은 "친근하게" 같은 형용사가 아니라 확인할 수 있는 조건으로 정의한다. 막연한 톤 지시는 결과가 들쭉날쭉하기 때문이다. `house_check.py --level N`이 이 조건을 잰다.

## 레벨을 고르면 달라지는 것

레벨을 명시적으로 고르면 SKILL.md 철칙 4(register 보존)가 그 레벨로 대체된다. 원문이 해라체여도 70을 고르면 요체로 바꾼다. **의미 불변·내용 앵커·서법 보존·숫자 보존은 레벨과 상관없이 그대로다.** 문체를 바꾸면서 내용을 더하거나 빼지 않는다.

레벨을 바꾸면 변경률이 30%를 쉽게 넘는다. 레벨 전환 작업에서는 변경률 30% 경고를 보고만 하고, 50% 롤백 규칙은 적용하지 않는다. 대신 숫자 누락·앵커 누락 검사를 더 엄격하게 본다.

## 다섯 기준점

### 0 — 공문·보도자료·보고서

| 항목 | 조건 |
|---|---|
| 종결 | 해라체(~다)나 합쇼체(~습니다) 중 하나로 통일. 보고서 본문 아래 항목은 명사형(-음/-함) 개조식 허용 |
| 금지 | 요체, 반말, 물음표·느낌표, 이모지, 담화표지(사실·그런데·요즘 같은 말 걸기), 감탄사 |
| 문장 | 주어를 밝힌다. 문장을 끝까지 완결한다(개조식 항목 제외) |
| 어휘 | 정확한 용어 우선. 단 번역투·AI 단골 표현 금지는 그대로 |
| 종결 배분 | 같은 유형 60% 이하, 2가지 이상. 사실은 과거형("밝혔다", "시행했다") |
| 표기 | 명사형은 '있음/없음'(있슴·없슴 아님) |

### 30 — 단정한 존댓말·칼럼·리포트·격식 뉴스레터

| 항목 | 조건 |
|---|---|
| 종결 | 합쇼체(~습니다) 중심 또는 해라체 칼럼. 요체는 10% 이하, 반말 0 |
| 허용 | 짧은 질문 한두 개, '사실' 정도의 담화표지 |
| 금지 | 이모지, 감탄사, 축약형(근데·이건·게) |
| 문장 | 길고 짧은 문장 섞기. 명사구 나열 대신 동사 |
| 종결 배분 | 같은 유형 50% 이하, 3가지 이상 |

### 50 — 블로그·카드뉴스·마케팅 기사 (하우스 룰 기본값)

하우스 룰 7장의 실측 리듬을 목표로 한다.

| 유형 | 목표 |
|---|---|
| ~합니다·~습니다 | 35% 안팎 |
| ~어요 | 20% 안팎 |
| ~는데요 | 8% |
| 감탄·질문 | 8% |
| ~고요 / ~죠 / ~예요 | 각 5~6% |

- 사람 글 표현(~거죠, ~는데요, ~잖아요, 요즘, 사실, 그런데, 이런)을 하나 이상
- 같은 유형 40% 이하, 3연속 금지, 3가지 이상
- 축약형은 드물게(근데·이건은 한 글에 한두 번까지)

### 70 — 친근한 대화체 (인스타 캡션·캐주얼 뉴스레터·커뮤니티 글)

| 항목 | 조건 |
|---|---|
| 종결 | 요체 중심(50% 이상). 합쇼체 25% 이하. 반말은 혼잣말 같은 짧은 문장에만 10% 이하 |
| 자주 쓰는 어미 | ~거든요, ~잖아요, ~더라고요, ~는데요, ~죠, ~네요 |
| 허용 | 축약형(근데, 이건, 그건, 게, 거), 주어 생략, 질문·감탄 |
| 사람 글 표현 | 두 개 이상 |
| 문장 | 15자 이하 짧은 문장이 자주 나온다. 한 문단 두세 문장 |
| 종결 배분 | 같은 유형 40% 이하, 4가지 이상 |

### 100 — 반말 구어 (친구에게 말하듯, 반말 SNS)

| 항목 | 조건 |
|---|---|
| 종결 | 해체(반말) 60% 이상. 존댓말(~요, ~습니다)과 섞지 않는다 |
| 자주 쓰는 어미 | ~어/~아, ~지, ~거든, ~잖아, ~더라, ~는데, ~네, ~냐 |
| 허용 | 감탄사(와, 아), 강조 부사(진짜, 완전, 되게), 축약형, 도치("좋더라 이거"), 주어 생략 |
| 문장 | 아주 짧은 문장과 한 호흡 긴 문장을 섞는다 |
| 주의 | 비속어·혐오 표현은 레벨과 상관없이 쓰지 않는다. 원문 사실관계는 그대로 |

## 기준점 사이의 숫자 (예: 15, 60, 85)

가까운 두 기준점의 조건을 비율대로 섞는다. 85라면 70을 바탕으로 하되, 문장의 절반쯤을 반말 질문·감탄·혼잣말로 바꾼다. 존댓말과 반말이 섞이는 구간(80~95)에서는 반말을 혼잣말·감탄·인용 같은 자리에만 두어서 어색하지 않게 한다.

## 레벨과 상관없이 금지

- 사물 존칭: "품절이십니다", "커피 나오셨습니다" → "품절입니다", "커피 나왔습니다". 높임 '-시-'는 사람이 주어일 때만 쓴다(문화체육관광부 공공언어 인식 조사, 3,000명 중 93.3%가 개선 필요로 응답).
- 과잉 공감·칭찬("정말 좋은 질문이에요!", "너무 멋져요") 새로 넣기
- 하우스 룰 2·3장 금지어·금지 표현

## 원문 레벨 추정

`house_check.py`가 문장 종결로 원문 구어도를 추정한다(해라체·명사형 0, 합쇼체 30, ~어요·~예요·~고요 60, ~는데요·~죠·기타 요체 70, 반말 100의 평균에 구어 표지 보정). 대략적인 값이니 레벨을 묻는 질문의 추천값을 정할 때만 쓴다.
