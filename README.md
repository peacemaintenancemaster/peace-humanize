# peace-humanize

peace-humanize는 사람이 쓴 것 같은 한글 글을 처음부터 작성하고 AI가 쓴 초안도 같은 기준으로 고치는 Claude 스킬입니다.

ChatGPT나 Claude로 쓴 글에는 문장마다 찍힌 쉼표와 "다만"으로 시작하는 문장 같은 흔적이 반복해서 남습니다. 저희 팀은 카드뉴스와 블로그 글을 다룰 때마다 이 흔적을 손으로 지워 왔습니다. 그러다 처음부터 흔적 없이 쓰는 편이 빠르다는 결론에 이르러 그동안 쌓은 기준을 하나의 스킬로 묶었습니다.

스킬을 설치해 두면 카드뉴스나 블로그 글을 요청할 때 Claude가 처음부터 이 기준에 맞춰 씁니다. 이미 있는 글을 붙여 넣으면 내용과 숫자와 고유명사는 그대로 두고 문체만 고칩니다.

> 숏폼은 단순히 짧은 영상이 아니라, 브랜드와 고객을 잇는 핵심 채널이에요. 결론적으로 숏폼은 마케팅의 새로운 패러다임이라고 할 수 있어요.

> 숏폼은 짧은 영상에 그치지 않고 브랜드가 고객을 만나는 통로가 되었습니다.

## 규칙의 출처

규칙은 사람이 만든 카드뉴스 120세트와 AI 비중이 높은 블로그 글 120세트를 나란히 놓고 비교해서 두 집단을 실제로 구분하는 항목만 남긴 결과입니다. 대표적인 항목은 쉼표입니다. 사람 글에서는 쉼표가 들어간 문장이 열 개 중 세 개를 넘지 않았는데 ACL 2025에 실린 한국어 AI 글 연구(KatFish)에서도 사람 글 26%와 AI 글 61%로 비슷한 차이가 나타났습니다.

번역투와 AI식 관용구를 잡는 규칙은 [im-not-ai](https://github.com/epoko77-ai/im-not-ai)에서 가져왔고 두 규칙이 충돌하면 카드뉴스 비교에서 나온 규칙을 따릅니다.

## 설치

```bash
npx skills add peacemaintenancemaster/peace-humanize
```

이 명령 하나로 Claude Code와 Codex와 Cursor에 모두 설치할 수 있습니다. 직접 설치하려면 저장소를 내려받아 `skills/peace-humanize` 폴더를 `~/.claude/skills/` 아래에 두면 되고 특정 프로젝트에서만 쓸 때는 해당 프로젝트의 `.claude/skills/`에 넣으면 됩니다. claude.ai 채팅에서 쓰려면 같은 폴더를 zip 파일로 묶어 설정의 스킬 메뉴에 올리십시오.

## 사용법

쓰고 싶은 글의 주제와 재료를 주면서 "카드뉴스 문구 써줘"처럼 요청하면 새 글을 작성합니다. 이미 쓴 글을 붙여 넣고 "AI 티 없애줘"라고 하면 윤문을 합니다. 고치지 않고 점검만 받고 싶다면 "이 글 AI 같아?"라고 물으면 됩니다.

작업 전에는 구어체 정도를 묻는데 세 구간 모두 존댓말입니다.

- 0: 보도자료와 공지에 맞는 단정한 문체("~했습니다", "~입니다")
- 50: 블로그와 카드뉴스에 맞는 문체("~습니다"와 "~어요"를 섞음)
- 100: 인스타그램 캡션에 맞는 편한 문체("~거든요", "~잖아요")

해라체로 쓴 칼럼이라면 "원문 톤 유지"를 고르면 문체를 그대로 둔 채 AI 흔적만 지웁니다. 25나 75 같은 중간 값도 가능합니다.

## 측정 스크립트

결과가 기준을 지켰는지는 파이썬만 있으면 실행되는 측정 스크립트로 검사합니다.

```bash
python skills/peace-humanize/scripts/house_check.py 고친글.txt --base 원문.txt --level 0
```

스크립트는 금지어와 쉼표 비율 같은 항목마다 PASS 또는 FAIL을 표시하고 `--base`로 원문을 지정하면 원문 숫자가 빠졌는지도 검사합니다.

## 한계

스크립트는 형태소 분석기 없이 종결어미를 끝 글자로만 분류하기 때문에 판정이 틀릴 때가 있습니다. "지수" 같은 금지 이름도 문맥에 따라 잘못 잡힐 수 있으니 잘못된 결과를 발견하면 이슈로 알려 주십시오.

규칙을 바꾸려면 `skills/peace-humanize/references/house-rules.md`를 수정하면 됩니다. 스크립트 판정까지 맞추고 싶다면 `house_check.py` 상단의 단어 목록도 함께 고쳐야 합니다.
